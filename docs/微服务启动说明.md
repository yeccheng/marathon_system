# 微服务启动说明（Spring Cloud Alibaba）

发令台 GUNSTART 已拆为 Nacos + Gateway + Feign 领域服务。对外入口仍是 **8081**，前端路径基本不变。

## 架构一览

| 进程 | 端口 | 说明 |
|------|------|------|
| Nacos | 8848 | 注册中心（需本机先启动） |
| marathon-gateway | **8081** | 网关、JWT、静态页 |
| marathon-auth | 8101 | 管理员登录发 JWT |
| marathon-event | 8102 | 赛事 / 封面 / 公开赛事 |
| marathon-registration | 8103 | 选手 / 报名 / OTP / 支付 |
| marathon-result | 8104 | 成绩 / 排名 / 统计 |
| marathon-ai-service | 8082 | 赛事助手（Boot 3，旁路） |

```text
浏览器 → Gateway:8081 → Nacos 发现 → 各业务服务
AI Tool → Gateway:8081/api/public/** → event
```

## 依赖环境

1. **JDK 8+**（业务服务；AI 需 **JDK 17/21**）
2. **MySQL 8**，库 `marathon_system`（脚本：`docs/数据库脚本/` + `sql/`）
3. **Redis** `localhost:6379`
4. **Nacos 2.x** 单机：`localhost:8848`（控制台默认 `http://localhost:8848/nacos`，账号 `nacos/nacos`）

## 本地配置（每个业务服务做一次）

在下列目录把 `application-local.yml.example` 复制为 `application-local.yml`，填写 MySQL / Redis 密码：

- `marathon-auth/`
- `marathon-event/`
- `marathon-registration/`
- `marathon-result/`
- `ai-service/`（API Key）

也可参考 [`microservice-application-local.yml.example`](./microservice-application-local.yml.example)。

**不要提交**填好密码的 `application-local.yml`。

## 启动顺序

1. 启动 Nacos、MySQL、Redis  
2. 根目录：`mvn -DskipTests install`  
3. 分别启动（IDE 或命令行）：

```bash
# 业务服务（JDK 8/11/17 均可，需能编译 Java 8）
cd marathon-auth && mvn spring-boot:run
cd marathon-event && mvn spring-boot:run
cd marathon-registration && mvn spring-boot:run
cd marathon-result && mvn spring-boot:run
cd marathon-gateway && mvn spring-boot:run

# AI（另开终端，必须 JDK 17+，推荐 21）
cd ai-service
set JAVA_HOME=C:\Program Files\Java\jdk-21.0.11
mvn spring-boot:run
```


4. 浏览器：
   - 公开平台：http://localhost:8081/
   - 管理台：http://localhost:8081/admin.html （`admin` / `123456`）
   - AI：公开页内「赛事助手」，或 `POST http://localhost:8081/api/ai/chat`

## 模块说明

| 模块 | 职责 |
|------|------|
| `marathon-common` | Result / JWT / Redis 工具 |
| `marathon-api` | Feign 接口与跨服务 DTO |
| `marathon-gateway` | 路由 + JWT 过滤器 + 静态资源 |
| `marathon-*` | 领域服务 |
| `ai-service` | 独立工程（不在 parent modules 内），自行 `mvn` |

根目录 `src/` 为**改造前单体备份**，父 POM 不再打包，请以各 `marathon-*` 模块为准。

## Feign 协作要点（答辩可讲）

- 报名成功/退赛：`registration` → Feign → `event` 增减 / 同步 `registered_count`
- 删除赛事：`event` → Feign → `registration` 是否存在报名
- 录入成绩：`result` → Feign → `registration` 校验报名摘要
- AI：HTTP 经 Gateway 调公开赛事 API；服务本身注册 Nacos 供网关转发
