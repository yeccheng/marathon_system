# 答辩 / 演示环境配置说明

课程或毕设答辩时，建议用独立本机配置，避免把密码和绝对路径写进可提交的 `application.yml`。

> **微服务版**：完整启动顺序见 [`微服务启动说明.md`](./微服务启动说明.md)。对外入口仍是 **http://localhost:8081**。

## 1. 需要准备的服务

| 组件 | 默认约定（演示机） | 说明 |
|------|-------------------|------|
| Nacos 2.x | `localhost:8848` | 注册中心，**先于业务服务启动** |
| MySQL 8 | 库名 `marathon_system`，账号 `root` | 先执行 `docs/数据库脚本/` 与 `sql/` 下演进脚本 |
| Redis | `localhost:6379` | 若设置了 `requirepass`，写入各服务 local 配置 |
| JDK | 业务服务 Java 8+；AI 需 17/21 | Gateway 端口 **8081** |
| 可选 | `ai-service` | 赛事助手；密钥放 `ai-service/application-local.yml` |

## 2. 各服务本地配置（必做一次）

在以下模块复制示例配置并填写密码：

```text
marathon-auth/src/main/resources/application-local.yml.example → application-local.yml
marathon-event/.../application-local.yml.example → application-local.yml
marathon-registration/... → application-local.yml
marathon-result/... → application-local.yml
ai-service/application-local.yml.example → application-local.yml
```

统一模板也可参考 [`microservice-application-local.yml.example`](./microservice-application-local.yml.example)。

填写项：

- `spring.datasource.password`：本机 MySQL 密码
- `spring.redis.password`：本机 Redis 密码（无密码可删该行；auth 可无 Redis）
- `marathon.upload.path`：封面目录（event 服务，演示可用 `uploads/`）

**不要把填好密码的 `application-local.yml` 提交到 Git。**

演示机常用示例值（仅课堂本机，勿用于公网）：

```yaml
spring:
  datasource:
    username: root
    password: "123456"
  redis:
    password: redis@2026
```

## 3. 前端入口（勿改混）

| 地址 | 文件 | 用途 |
|------|------|------|
| http://localhost:8081/ | `marathon-gateway/.../static/index.html` | 公开报名平台（在用） |
| http://localhost:8081/admin.html | `marathon-gateway/.../static/admin.html` | 管理台（在用） |
| — | `docs/前端源文件/index.html` | **已归档旧稿**，不参与运行 |
| — | 根目录 `src/` | **改造前单体备份**，父 POM 不打包 |

管理端脚本：`admin-app.js`；公开端：`public-app.js`。AI 默认同源走 Gateway `/api/ai/**`。

## 4. 封面图演示

1. 目录 `uploads/` 已放示例图：`demo-cover-wall.jpg`、`demo-cover-finish.jpg`
2. 可选执行：`sql/seed_demo_covers.sql`
3. 或登录管理台 → 编辑赛事 → 上传封面（由 **event** 服务写入 `uploads/`）

访问示例：`http://localhost:8081/uploads/demo-cover-wall.jpg`

## 5. 答辩前快速检查

- [ ] Nacos 已启动，控制台能看到 gateway / auth / event / registration / result（及 AI）
- [ ] MySQL 库已导入，管理端可登录（`admin` / `123456`）
- [ ] Redis 可连，与各服务 `application-local.yml` 一致
- [ ] 各业务模块存在 `application-local.yml`
- [ ] 浏览器打开公开页与 `/admin.html` 均正常
- [ ] 可选：赛事助手能回答「有哪些可报名赛事」

## 6. 与 Git 的关系

根目录已 `git init`。演进 SQL、各 `marathon-*` 模块、`ai-service` 应随提交一起走；`application-local.yml` 与用户上传的 `uploads/*` 不进仓库。
